# Online Job Portal Management System

## Project Overview

The Online Job Portal Management System is a database management project developed using MySQL. The project is designed to provide a platform where job seekers can search and apply for jobs, employers can post vacancies, and administrators can manage the entire system efficiently.

This project demonstrates the practical implementation of database concepts such as tables, relationships, indexes, views, triggers, and user role management.

---
## Objectives

- Create a centralized platform for recruitment activities.
- Provide efficient job searching and application processing.
- Demonstrate advanced database management concepts.
- Improve query performance through indexing.
- Maintain data integrity using triggers.
- Simplify reporting and data retrieval through views.

---
## Features

### Administrator
- Manage users and employers
- Monitor job postings
- View job applications
- Maintain system records
- Generate reports

### Employer
- Register and maintain company profiles
- Post job vacancies
- Update job details
- View applicants for posted jobs

### Job Seeker
- Create an account
- Search available jobs
- Apply for jobs
- Track application status
- Maintain personal profile information

---

## Database Components

### Tables
The system contains multiple tables to store and manage data related to:
- Administrators
- Users
- Employers
- Jobs
- Applications
- Categories

### Indexes
Indexes are implemented to improve the speed and efficiency of data retrieval operations.

### Views
Views are used to simplify complex queries and provide organized access to frequently requested data.

### Triggers
Triggers automate database operations and help maintain consistency and integrity of data.

## System Modules

### Employer Management

### Job Management

### Application Management

Provides complete control over users, employers, jobs, and applications.
